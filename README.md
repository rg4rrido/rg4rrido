### 🚀 Proyectos Personales: Infraestructura y HomeLab
Diseño, despliegue y gestión de un entorno **HomeLab orientado a simular infraestructuras reales**, enfocado en virtualización, automatización y ciberseguridad:

- **💻 Infraestructura física:**
    - Rack con servidores dedicados
    - NAS con OpenMediaVault para almacenamiento centralizado
    - Nodo Proxmox como base de virtualización
- **☸️ Orquestación de contenedores:**
    - Cluster K3s con 3 Raspberry Pi
    - Despliegue de servicios distribuidos y pruebas de alta disponibilidad
- **🤖 Automatización (IaC):**
    - Gestión completa mediante Ansible
    - Provisionamiento, configuración y mantenimiento automatizado

Este entorno me permite experimentar, romper y reconstruir sistemas en escenarios similares a producción.
