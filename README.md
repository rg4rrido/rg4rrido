### 🚀 Proyectos Personales: Infraestructura y HomeLab
He diseñado y montado un **HomeLab de alto rendimiento** desde cero, enfocado en la gestión de infraestructuras escalables y la automatización de despliegues:

- **💻 Servidores:** Montaje de un rack físico que integra:
    
    - **NAS (OpenMediaVault):** Almacenamiento centralizado y gestión de datos.
        
    - **Hypervisor (Proxmox):** Nodo principal para la virtualización de servicios de red.
        
- **☸️ Cluster K3s:** Despliegue de un cluster de Kubernetes utilizando **3 Raspberry Pis**, configurado para la orquestación de contenedores y alta disponibilidad.
    
- **🤖 Automatización (IaC):** Gestión integral de todo el stack mediante **Ansible**, permitiendo la configuración, el despliegue y el mantenimiento de las máquinas desde mi equipo personal mediante código (Infrastructure as Code).
